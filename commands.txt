# --- 1. Telemetry Control (텔레메트리 제어) ---
# 캔위성의 데이터 전송을 켭니다. (발사 전 필수)
CMD,1062,CX,ON

# 캔위성의 데이터 전송을 끕니다.
CMD,1062,CX,OFF


# --- 2. Time Synchronization (시간 동기화) ---
# 캔위성의 시간을 GPS 시간으로 동기화합니다. (권장)
CMD,1062,ST,GPS

# 캔위성의 시간을 특정 시간(UTC)으로 수동 설정합니다. (예: 13시 35분 59초)
CMD,1062,ST,13:35:59


# --- 3. Calibration (센서 영점 조절) ---
# [G1] 발사 패드 위에서 고도를 0m로 초기화합니다.
CMD,1062,CAL


# --- 4. Simulation Mode (시뮬레이션 모드) ---
# [G11] 시뮬레이션 모드를 활성화할 준비를 합니다. (첫 번째 단계)
CMD,1062,SIM,ENABLE

# [G11] 시뮬레이션 모드를 실제로 작동시킵니다. (두 번째 단계 - ENABLE 후 전송)
CMD,1062,SIM,ACTIVATE

# 시뮬레이션 모드를 끄고 비활성화합니다.
CMD,1062,SIM,DISABLE

# [G12] 시뮬레이션용 압력 데이터 단건 전송 예시 (자동화되지만 수동 테스트용)
# 101325 Pa = 해수면 기압
CMD,1062,SIMP,101325


# --- 5. Mechanism Control (메커니즘 작동) ---
# [G17] 특정 장치(DEVICE)를 작동시킵니다.
# 주의: 'DEVICE' 부분은 팀이 정한 이름(예: RELEASE, BUZZER)으로 바꿔야 합니다.

# 예시 1: 낙하산 분리 장치 작동 (가정)
CMD,1062,MEC,RELEASE,ON

# 예시 2: 부저(소리) 끄기 (가정)
CMD,1062,MEC,BUZZER,OFF

# 포맷 참고용: CMD,<TEAM_ID>,MEC,<DEVICE_NAME>,<ON/OFF>
CMD,1062,MEC,MY_DEVICE_NAME,ON
